# 랜딩 페이지 기능 요구사항

> 이 문서는 새로 만들 주식 리포트 랜딩 페이지가 **무엇을 할 수 있어야 하는지**를 정리한 것입니다.
> 어떻게 만드는지(기술적인 부분)는 담지 않았고, 사용자가 화면에서 겪는 경험 위주로 적었습니다.

---

## 1. 이 페이지는 무엇인가요?

방문한 사람이 관심 있는 종목을 검색하면, 그 종목의 주가 정보와 AI가 만든 리포트를 미리 보여줍니다.
리포트의 핵심 내용(한 줄 결론, 분석 결과)은 살짝 가려두고, 궁금하면 아래 신청 폼으로 무료 리포트를 신청하도록 유도합니다.

- 휴대폰으로 보기 편한, 위에서 아래로 쭉 내려가는 **세로로 긴 형태**입니다.
- 광고나 링크를 타고 처음 들어온 사람도 바로 이해할 수 있어야 합니다.

---

## 2. 화면 구성 (위에서 아래 순서)

1. **첫인상 영역** — 서비스가 무엇인지 한눈에 알 수 있는 소개
2. **오늘의 현황** — 오늘 신청자 수, 이번 주 무료 발송 잔여 수
3. **지금 많이 찾는 종목** — 인기 종목 8개를 버튼(칩) 형태로 노출
4. **검색창** — 종목을 검색하는 곳
5. **리포트 미리보기** — 검색한 종목의 주가와 리포트 (일부 가림)
6. **신청 폼** — 무료 리포트를 신청하는 곳 (화면 아래쪽)

---

## 3. 기능별 상세 요구사항

### 3-1. 오늘의 현황 (신뢰감·긴박감 주기)

- **오늘 신청한 사람 수**를 보여줍니다.
- **이번 주에 무료로 보내드릴 수 있는 남은 수량**을 보여줍니다.
- 이 숫자들은 실제 상황에 맞게 자동으로 갱신되어야 합니다. (계속 그 자리에서 새 값으로 바뀜)
- "얼마 안 남았다"는 느낌을 주어 신청을 망설이지 않게 합니다.

### 3-2. 지금 많이 찾는 종목

- 요즘 관심이 높은 종목 **8개**를 골라 버튼 형태로 보여줍니다.
- 방문자가 검색어를 직접 떠올리지 않아도, 버튼만 눌러 바로 리포트를 볼 수 있게 합니다.
- 어떤 종목을 노출할지는 시장 상황에 따라 자동으로 정해집니다.

### 3-3. 검색

- 검색창에 회사 이름이나 종목을 입력하면, 아래에 해당 리포트 미리보기가 나타납니다.
- 검색 가능한 종목은 **국내 상장 종목 전체(코스피 약 833개사, 코스닥 약 1,818개사, 합계 약 2,651개사)** 입니다.
- 입력하는 도중에도 결과를 빠르게 찾아 보여주면 좋습니다.

### 3-4. 리포트 미리보기

리포트는 크게 **회사 정보 → 주가 → 리포트 본문** 순서로 구성됩니다.

**(1) 회사 정보 (맨 위)**
- 회사 로고나 마크는 넣지 않고 **회사 이름만** 표기합니다.
- 종목 번호, 어느 시장(코스피/코스닥)인지, 어떤 산업인지 함께 표기합니다.

**(2) 주가 정보**
- 현재가, 오늘 고가, 오늘 저가, 52주 최고가, 52주 최저가를 보여줍니다.
- 최근 **3개월간 주가 변화를 그래프(차트)** 로 보여줍니다.
- 주가 숫자는 매일 정해진 시간에 최신 값으로 갱신됩니다.

**(3) 리포트 본문**
- 리포트 **제목**을 보여줍니다. 제목은 "~일까?" 처럼 **질문 형식**입니다.
- 리포트가 어떤 종류(분류)인지 함께 표기합니다.
- 해당 종목과 관련된 **최신 뉴스를 5개** 함께 보여줍니다.

**(4) 핵심 내용 가리기**
- **한 줄 결론**과 **자세한 분석 결과**는 일부러 흐리게 가려둡니다.
- "전체 내용이 궁금하면 신청하세요" 하는 흐름으로 자연스럽게 신청 폼으로 연결합니다.

### 3-5. 무료 리포트 신청 (가장 중요)

- 화면 아래쪽에 신청 폼을 둡니다.
- 신청자는 **휴대폰 번호 인증**을 거쳐야 합니다.
  - 번호를 입력하면 인증 절차가 진행되고, 확인이 되어야 신청이 완료됩니다.
- 신청이 완료되면, 신청 정보가 안전하게 기록되고 담당자에게도 알림이 갑니다.
- 어디서 들어온 방문자인지(광고 유입 등)도 함께 기록되면 좋습니다.

---

## 4. 저장되어야 하는 정보

서비스 운영을 위해 아래 정보가 기록됩니다.

- **신청자 정보(리드)** — 무료 리포트를 신청한 사람의 정보
- **휴대폰 인증 기록** — 인증을 요청하고 확인한 내역 (안전하게 보관)
- **주가 정보** — 종목별 시세, 매일 갱신
- **리포트 제목·분류** — 각 종목의 리포트 제목과 분류 (한 번 정해지면 거의 바뀌지 않음)

---

## 5. 톤과 느낌

- 어렵고 딱딱한 금융 용어보다는, 누구나 이해할 수 있는 쉬운 말투로 씁니다.
- 과장된 광고 문구("최고의", "혁신적인" 등)는 쓰지 않습니다.
- 버튼 문구는 행동이 분명하게 드러나도록 씁니다. (예: "신청하기", "확인")
- 휴대폰에서 봤을 때 가장 편해야 합니다.

---

## 6. 꼭 지켜야 할 원칙

- 방문 → 검색 → 리포트 미리보기 → 신청까지, **막힘 없이 한 흐름**으로 이어져야 합니다.
- 핵심 내용은 가려서 신청을 유도하되, 방문자가 속았다는 느낌은 들지 않게 합니다.
- 오늘의 현황 숫자와 주가 정보는 **항상 최신처럼** 보여야 신뢰가 생깁니다.
- 신청 과정은 최대한 간단해야 하며, 휴대폰 인증 외에 불필요한 절차는 넣지 않습니다.
